## 1. 目的と背景 (Intent and the Why)

トップページの優しい雑誌風デザイン（純白 `#ffffff`・オフホワイト `#fafafa`・リバースカイブルー `#72bcd9`・明朝体見出し・写真に文字を重ねない開放感）は確立された一方、サイト全体として以下の3つの課題を解決する必要がある。

1. **ヘッダーメニューからの専用ページ化と情報ボリュームの拡充**
   - 現状はヘッダーメニューをクリックするとトップページ内の該当箇所（`/#concept` 等）へスクロールするだけとなっており、サイト全体の情報量が不足している。
   - トップページは「世界観を味わう雑誌の表紙・目次」と位置づけ、ヘッダーメニューからは**各項目専用のサブページ**へ遷移して詳細な情報を確認できるようにする。
2. **プログラム説明画面（一覧および詳細モーダル）の抜本的刷新**
   - 元のサイトのプログラムページ（`studio/index.html`、`outdoorfitness-program/index.html` 等）は、青いピル型ボタンが並ぶだけで写真がなく、クリック後のポップアップ（モーダル）も白い枠に短い文字が出るだけで「どんな環境で、実際に何をして、身体と心（精神面）にどんな効果があるのか」が伝わらない。
   - 一覧画面は**「3列のすっきりした写真グリッド＋概要（B案）」**とし、クリック時のポップアップは**「Instagram動画/リール導線・行う環境・実際に行う動き・身体への効果×精神への効果が視覚的に伝わる詳細画面（A案）」**を組み合わせたハイブリッド構成に刷新する。
3. **Instagram動画・画像の活用と、トップページへの「キッズスクール」追加**
   - 公式Instagram（`@riverpark.tokyo`）のリール動画やビジュアルを各プログラム詳細・トップページ・専用ページに活用し、一目でスタジオや多摩川の空気感が伝わるようにする。
   - トップページの `PROGRAM` セクションに**お子様向けの「キッズスクール（KIDS SCHOOL）」**を並置し、大人向けプログラムと同様に分かりやすく案内する。

## 2. ゴール・非ゴール・アンチゴール (Goals, Non-Goals, Anti-Goals)

### Goals（達成すること）
1. **トップページ（`index.html` / `css/top.css`）の拡充**:
   - `PROGRAM` セクションに「キッズスクール（キッズボルダリング・フリースタイルダンス）」（`/kids/`）を追加し、5つのプログラムカテゴリー（ヨガ＆ピラティス／ボルダリング／アウトドア／ラウンジ＆カフェ／キッズスクール）を丸型写真モチーフで並置する。
   - 各セクションの詳細リンク先を、新設・拡充する各専用ページ（`/concept/`、`/lounge/`、`/program/`、`/instructor/`、`/plan/`、`/access/`）へ接続する。
   - `INSTAGRAM` セクションにリール動画プレビュー（ループ映像＋`@riverpark.tokyo` への導線）を組み込み、動きのある空気感を伝える。
2. **共通ヘッダー・フッター（`include/header.html` / `include/footer.html`）の専用ページリンク化**:
   - ヘッダーナビゲーションをトップページ内アンカーから各専用ページURLへ変更する：
     - `コンセプト` → `/concept/`
     - `プログラム` → `/program/`
     - `インストラクター` → `/instructor/`
     - `ワークラウンジ` → `/lounge/`
     - `プラン` → `/plan/`
     - `スケジュール` → `/program/#schedule`（【Builder's Call】月間スケジュールPDF・予約カレンダーへの導線を `/program/#schedule` に配置し、既存会員の利便性も維持する）
     - `アクセス` → `/access/`
     - `体験のご予約はこちら` → 現行のスポーツクラブNAS予約システムURL（`https://rsvprime.nas-club.co.jp/members/NR020?queryParam=%7B%22mode%22%3A2,%22tenpo%22%3A140%7D&digest=79fe70ca810b3d45ebcc2c8f008747675a0879f44958efb06393c6001b4660ae`）を維持（スマホメニュー内の `初めての方へ` `/first-time/` および `問合せ` フォームリンクも維持）。
3. **プログラム一覧＆詳細モーダル（`studio/index.html`、`outdoorfitness-program/index.html`、`bouldering/index.html`、`kids/index.html`）の「3列グリッド＋リッチモーダル」刷新**:
   - **一覧画面（3列グリッド）**：PC表示で横3列（`grid-template-columns: repeat(3, 1fr)`、タブレット2列、スマホ1列）、背景枠線なしのクリーンな長方形写真（比率 `3:2`）の下に「環境・強度ラベル」「クラス名」「2行の簡潔な内容＆心身効果」「詳細・動画を見る ＞」を表示する。
   - **詳細ポップアップ（モーダル）**：カードをクリックすると開くモーダル内に、①ビジュアル（ループショート動画またはスタジオ・フィールド写真＋`@riverpark.tokyo` リール導線）、②`ENVIRONMENT（行う環境）`、③`WHAT WE DO（実際に行うこと）`、④`PHYSICAL EFFECT（身体への効果）` × `MENTAL EFFECT（精神・心への効果）` の2カラム解説、⑤`ビジターで予約する` ボタン（現行の `rsvprime.nas-club.co.jp` URL）を表示する。
4. **6つの専用ページの構築・大幅拡充**:
   - `/concept/index.html`（新規作成）
   - `/lounge/index.html`（施設・ワークラウンジ専用ページとして3列施設グリッド等を大幅拡充）
   - `/program/index.html`（全プログラム総合案内＆スケジュールページとして新規作成）
   - `/instructor/index.html`（全インストラクターの一覧・カテゴリーフィルター・詳細ページとして新規作成）

### Non-Goals（スコープ外）
- 独自の予約決済バックエンド構築（予約導線はすべて現行コードベースの公式予約システム `https://rsvprime.nas-club.co.jp/members/NR020...` および既存フォーム `https://reg18.smp.ne.jp/regist/is?...` をそのまま使用する）。
- 既存のサードパーティJSライブラリ（`jquery.min.js`、`modaal.min.js`、`slick.min.js`）自体の書き換え。

### Anti-Goals（絶対にやらないこと）
- **カードサイズの肥大化禁止**：プログラム一覧や施設一覧を2列の巨大な枠付きカードにしない。必ずユーザー承認済みの**「枠線なしのすっきりした3列写真グリッド」**を守る。
- **営業感・LP感の混入禁止**：原色のバッジ、絵文字（🌿🧘‍♀️等）の多用、煽り文句、写真の上に大きな文字を重ねるレイアウトは一切行わない。
- **期限切れを起こすInstagram CDN直リンクの禁止**：Instagramの一時画像URL（`scontent-*.cdninstagram.com`）は数時間で403エラーになるため直接 `<img>` に貼らず、ローカルの厳選実写素材（既存80枚超＋生成ビジュアル・ループ映像）と公式Instagram（`https://www.instagram.com/riverpark.tokyo/`）への導線を組み合わせる。

## 3. ユーザーが確定した設計仕様 (Decisions Made by Partner)

### 3.1 プログラム一覧＆詳細ポップアップ（B案＋A案ハイブリッド・3列グリッド）
- **一覧表示（ページ上）**：
  - ユーザー提示リファレンス画像（`FACILITY & RENTAL 施設フロア・スタジオレンタル`）と同じサイズ感・余白感の **3列グリッド（`repeat(3, 1fr)`, `gap: 36px 28px`）**。
  - 各アイテムの構成：
    1. 写真（`aspect-ratio: 3 / 2`、`object-fit: cover`）
    2. 環境・強度サブタイトル（例：`2F 自然光スタジオ ｜ 強度 ★〜★★`、色：`#72bcd9`）
    3. プログラム名（例：`アロマリラックスヨガ 〜季節の養生〜`）
    4. 2行解説（何をどのように行い、身体と心にどう効くかの要約）
    5. `詳細・動画を見る ＞` リンク（クリックでModaalポップアップを起動）
- **詳細ポップアップ（モーダル内）**：
  - リバーパークのトーン（白 `#ffffff`、オフホワイト `#fafafa`、アクセント `#72bcd9`、明朝体見出し、絵文字なし）で統一。
  - 構成要素：
    1. カテゴリーラベル＋クラス名＋運動強度・対象目安
    2. 左カラム：クラスの雰囲気が伝わる映像プレビュー（自動再生ループ映像または高解像度シーン写真）＋ `▶ Instagram（@riverpark.tokyo）でクラスの雰囲気を見る` リンク
    3. 右カラム：
       - `ENVIRONMENT（行う環境）`：多摩川の景色、自然光、無垢材の床、アロマの香り、芝生の開放感など「どんな場所で行うか」
       - `WHAT WE DO（実際に行うこと）`：初心者にも具体的にイメージできる動きや呼吸の進め方
    4. 下段2カラム（`#fafafa` 背景ボックス）：
       - `PHYSICAL EFFECT（からだへの心地よい変化）`：肩こり緩和、姿勢改善、体幹強化、血流・巡り改善など
       - `MENTAL EFFECT（こころへの心地よい変化）`：思考の緊張解放、自律神経の調整、リフレッシュ・睡眠の質向上など
    5. フッターCTA：`ビジターで予約する`（現行の `rsvprime.nas-club.co.jp` URL）＋ `CLOSE` ボタン

### 3.2 トップページ「PROGRAM」セクションへのキッズスクール追加
